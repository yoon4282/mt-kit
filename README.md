# 🎤 MT MC 키트

QR 연동형 MT·동아리 레크리에이션 진행 도구. 백엔드 없이 정적 호스팅만으로 동작합니다.

**배포 주소:** https://yoon4282.github.io/mt-kit/ (main 브랜치에 push 하면 자동 배포)

| 화면 | 주소 | 용도 |
|---|---|---|
| 전광판 | `/` | 노트북·빔프로젝터. QR, 문제, 버저 현황, 순위표 + 하단 MC 컨트롤 패널 |
| MC 리모컨 | `?role=mc&room=방ID&key=MC키` | MC 폰. 전광판의 MC QR로 접속 |
| 참가자 | `?room=방ID` | 참가자 폰. 닉네임·팀 선택 후 버저 |

- 참가 링크는 전광판의 [카카오톡 공유] 버튼으로 단톡방에 바로 보낼 수 있어요 (카카오 키가 없으면 기기 공유창 → 링크 복사 순으로 대체).

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 Wi-Fi의 폰에서 접속 가능하도록 --host)
npm run build      # 타입 검사 + dist/ 빌드
npm run preview    # 빌드 결과 미리보기
```

- 폰으로 테스트하려면 같은 Wi-Fi에서 터미널에 표시되는 `Network: http://192.168.x.x:5173` 주소로 전광판을 여세요.
  (localhost 로 열면 QR 주소도 localhost 가 되어 폰에서 열리지 않습니다. 전광판 패널의 [QR 주소]에서 바꿀 수도 있어요.)
- 폰 없이 시연: 전광판 하단 패널 → [🤖 시연용 봇] 추가 → [버저 열기] → 점수 부여.
- QR 카드의 [새 탭 열기]로 참가자/MC 화면을 같은 PC 에서 띄워 실제 P2P 통신도 확인할 수 있어요.
- `?room=방ID&bot=1` 로 열면 실제 PeerJS 로 접속해 자동으로 버저·답 제출을 하는 테스트 봇이 됩니다 (탭 하나 = 참가자 한 명).
- 전광판을 처음 열면 한 번 클릭해야 음악·낭독이 재생돼요 (브라우저 자동재생 정책).

## 퀴즈 진행 순서

종류 → 카테고리 선택 → [첫 문제 불러오기] → [문제 공개 + 시작] → (시간 종료 시 자동 마감) → [정답 공개] → 점수 부여 → [다음 문제]

- **🎲 랜덤 출제:** 종류 버튼 옆 [랜덤 출제]는 그 종류 전체에서, 카테고리 안의 [랜덤 출제 (N문제 남음)]은 그 카테고리에서 **아직 안 낸 문제** 중 무작위로 하나를 불러옵니다. 카테고리 제목 옆 [랜덤] 토글을 켜면 [다음 문제]도 순서 대신 무작위로 나와요.
- 버저형(초성·이모지·스피드·음악·줌인·가사 낭독): 첫 버저가 들어오면 타이머가 멈추고, [1등 오답 → 다음 순서]로 기회를 넘깁니다. 마감 단계와 타이머 없이 [문제 공개 + 시작] → [정답 공개]로 진행.
- O/X: 기본 5초. 참가자 폰에서 선택, 정답 공개 후 [정답자 전원 선택]으로 한 번에 점수 부여.
- 4지선다: 기본 5초. 정답 공개 순간 **스피드 자동 채점** — 가장 빨리 맞힌 사람 30점, 그 뒤로 1점씩 감소(최소 1점). 팀전에서는 팀에서 가장 빨리 맞힌 사람 기준으로 팀 순위를 매겨 30·29·28·27점. [되돌리기] 한 번으로 전체 취소.
- 음악: 유튜브 공식 영상을 가려 둔 채 하이라이트 구간만 1초/3초/5초 재생, 정답 공개 시 영상 표시. **노래가 끝나야 버저가 열리고**, 다시 들려줄 때는 재생 동안 버저가 잠시 닫혀요(누른 순서는 유지).
- 🔍 줌인: 사진의 일부를 400%로 확대해 보여 주고, [↔ 범위 넓히기]로 400% → 200% → 100%(전체) 순으로 넓혀 갑니다. [🖼 전체 공개], [↺ 400%로] 버튼도 있어요. 단계별 권장 배점은 **+30 → +20 → +10** 이며 점수 패널에 함께 표시됩니다. 정답 공개 화면에 사진 출처가 표시돼요.
- 🤖 가사 낭독: [가사 낭독 재생]을 누르면 전광판 스피커로 브라우저 음성합성(기계음)이 가사를 읽고, 1초 음악처럼 **낭독이 끝나야 버저가 열려요.** 다시 들려줄 때는 낭독 동안 버저가 잠시 닫혀요(누른 순서는 유지). [🔁 다시 듣기], [🐢 0.8배속], [🐇 1.3배속] 지원.
  - **힌트:** 줌인처럼 [💡 힌트 공개]로 단계를 올리면 전광판(과 참가자 폰)에 힌트가 뜹니다. 1단계 힌트 없음 **+30** → 2단계 가수(+발매 연도) **+20** → 3단계 제목 초성(영어 제목은 글자 수) **+10**. 권장 배점은 점수 패널에 표시돼요. [↺ 힌트 숨기기]로 되돌릴 수 있어요. 한국어 음성이 없는 PC 에서는 경고가 뜨니 윈도우 설정 → 시간 및 언어 → 음성에서 한국어를 추가하세요.
- MC 폰이 연결되면 전광판의 MC QR 은 자동으로 숨겨집니다 ([MC QR 다시 보기]로 다시 표시).
- **재입장:** 같은 폰·같은 브라우저로 다시 들어오면 자동으로 이어집니다. 다른 브라우저(예: 카카오톡 QR 스캐너 → 기본 카메라)나 저장소가 지워진 폰이라도 **전과 같은 닉네임**으로 입장하면 기존 참가자의 점수·팀을 이어받아요. 단, 그 닉네임의 기존 기기가 지금 사용 중이면 동명이인으로 보고 새 참가자로 등록합니다.
- 전광판 패널의 비밀 정답지는 빔프로젝터에 노출되지 않도록 기본으로 가려져 있고, 누르고 있는 동안만 보입니다.
- [🏆 순위 발표] 버튼으로 현재 모드(개인/팀) 시상대 화면을 띄웁니다. 개인 점수와 팀 점수는 서로 독립적으로 쌓여요.

| 🎵 1초 음악 | 버저 | 없음 (MC 판정) | 최신 K-POP 50곡 / 인기 K-POP 50곡 |
| 🔍 줌인 | 버저 | 없음 (MC 판정) | 브랜드 로고 / 음식 / 동물 / 생활 사물 / 연예인 얼굴 (각 20문제, 총 100문제) |
| 🤖 가사 낭독 | 버저 | 없음 (MC 판정) | K-POP 가사 50곡 |

- 문제는 `src/data/quizzes/*.ts` 에 있어요. 초성 퀴즈는 정답만 적으면 초성이 자동으로 만들어집니다.
- 초성·OX·4지선다·이모지·스피드는 예능(지구오락실·신서유기) 스타일로 구성했어요. `explanation`(해설)은 정답 공개 때 전광판에, `hint`(MC 드립 한 줄)와 `accept`(인정 답안)는 MC 비밀 정답지에만 보여요. 버저형은 MC가 판정하고, OX·4지선다만 자동 채점됩니다.
- 음악은 유튜브 공식 영상(임베드 허용 확인)의 "가장 많이 다시 본 구간"부터 재생해요. 어색한 곡은 전광판 패널 [🛠 도구 → 곡 구간 조정]에서 시작 위치·영상을 바꿀 수 있고, 노트북에 저장됩니다.
- 줌인 사진은 위키미디어 커먼즈 이미지를 외부 URL 로 불러옵니다 (`src/data/zoomPhotos.ts`, 첫 확대 위치는 사진마다 `fx`/`fy` 0~100%). 문제를 불러올 때 미리 받아 두고, 못 불러오면(오프라인 등) 직접 그린 SVG(`src/data/zoomArt*.ts`)로, 그것도 없으면 안내 카드로 대체돼요. **출처·라이선스는 [CREDITS.md](CREDITS.md)** 를 보세요 (로고는 상표권자 자산, 인물 사진은 비상업 퀴즈 용도로만 사용).
- 가사 낭독은 저작권 때문에 곡마다 **짧은 후렴 한 구절**만 넣었어요. 가사·발매 연도는 검수가 덜 됐으니 **행사 전에 한 번씩 들어 보고** 틀린 부분은 `src/data/quizzes/tts.ts` 에서 고쳐 주세요. 힌트는 발매 연도 + 초성(영어 제목은 글자 수)으로 자동 생성됩니다.
- 효과음(버저·정답·오답·시작·째깍·시간 종료·점수·입장·팡파르)은 Web Audio 로 실시간 합성. 전광판 상단에서 끌 수 있어요.

## 배포

- **자동:** `main` 브랜치에 push 하면 `.github/workflows/deploy.yml` 이 `npm ci` → `npm run build` 후 `dist/` 를 GitHub Pages 에 배포합니다 (수동 실행은 Actions 탭 → Run workflow).
- **수동:** `npm run build` → `dist/` 폴더를 그대로 GitHub Pages 또는 Vercel 에 올려도 됩니다 (`base: './'` 로 하위 경로에서도 동작).
- **카카오톡 공유:** `src/config.ts` 의 `KAKAO_JS_KEY`(공개용 JavaScript 키)를 쓰며, Kakao Developers 앱 설정의 [플랫폼 → Web → 사이트 도메인]에 배포 주소(`https://yoon4282.github.io`)가 등록돼 있어야 동작합니다. 비워 두면 기기 공유창 / 링크 복사로 대체돼요.

## 구조

```
src/
  types.ts              도메인 타입 (Player.personalScore / Team.teamScore 독립)
  config.ts             카카오 공유 키
  game/reducer.ts       모든 게임 로직 — 개인전 점수와 팀전 점수를 섞는 경로 없음
  game/selectors.ts     순위·공개/MC 스냅샷 분리
  game/bots.ts          시연용 봇 (실제 참가자와 같은 액션 사용)
  net/protocol.ts       PeerJS 메시지 정의
  net/hostPeer.ts       전광판(호스트) 네트워크
  net/clientPeer.ts     폰 네트워크 (자동 재접속, 하트비트)
  data/quiz.ts          퀴즈 타입·문제 생성 헬퍼 (초성 변환 등)
  data/quizzes/         퀴즈 8종 문제 데이터 (index.ts 에서 등록)
  data/zoomPhotos.ts    줌인 사진 URL·출처·확대 위치
  data/zoomArt*.ts      줌인 대체용 SVG 그림
  audio/                효과음(sfx), 유튜브 플레이어
  components/           ControlPanel·QuizControl(전광판·MC 공용), Leaderboard, QRCard, ZoomFrame, ShareButton …
  screens/              board (전광판·TTS 낭독기·음악 플레이어·시상대) / mc / player
```

> 통신: PeerJS 공개 시그널링 서버는 연결을 맺을 때만 사용되며, 게임 데이터는 브라우저끼리 직접(P2P) 주고받습니다.
