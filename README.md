# 🎤 MT MC 키트

QR 연동형 MT·동아리 레크리에이션 진행 도구. 백엔드 없이 정적 호스팅만으로 동작합니다.

| 화면 | 주소 | 용도 |
|---|---|---|
| 전광판 | `/` | 노트북·빔프로젝터. QR, 문제, 버저 현황, 순위표 + 하단 MC 컨트롤 패널 |
| MC 리모컨 | `?role=mc&room=방ID&key=MC키` | MC 폰. 전광판의 MC QR로 접속 |
| 참가자 | `?room=방ID` | 참가자 폰. 닉네임·팀 선택 후 버저 |

## 실행

```bash
npm install
npm run dev
```

- 폰으로 테스트하려면 같은 Wi-Fi에서 터미널에 표시되는 `Network: http://192.168.x.x:5173` 주소로 전광판을 여세요.
  (localhost 로 열면 QR 주소도 localhost 가 되어 폰에서 열리지 않습니다. 전광판 패널의 [QR 주소]에서 바꿀 수도 있어요.)
- 폰 없이 시연: 전광판 하단 패널 → [🤖 시연용 봇] 추가 → [버저 열기] → 점수 부여.
- QR 카드의 [새 탭 열기]로 참가자/MC 화면을 같은 PC 에서 띄워 실제 P2P 통신도 확인할 수 있어요.
- `?room=방ID&bot=1` 로 열면 실제 PeerJS 로 접속해 자동으로 버저·답 제출을 하는 테스트 봇이 됩니다 (탭 하나 = 참가자 한 명).
- 전광판을 처음 열면 한 번 클릭해야 음악이 재생돼요 (브라우저 자동재생 정책).

## 퀴즈 진행 순서

종류 → 카테고리 선택 → [첫 문제 불러오기] → [문제 공개 + 시작] → (시간 종료 시 자동 마감) → [정답 공개] → 점수 부여 → [다음 문제]

- 버저형(초성·이모지·스피드·음악): 첫 버저가 들어오면 타이머가 멈추고, [1등 오답 → 다음 순서]로 기회를 넘깁니다. 마감 단계와 타이머 없이 [문제 공개 + 시작] → [정답 공개]로 진행.
- O/X: 기본 5초. 참가자 폰에서 선택, 정답 공개 후 [정답자 전원 선택]으로 한 번에 점수 부여.
- 4지선다: 기본 5초. 정답 공개 순간 **스피드 자동 채점** — 가장 빨리 맞힌 사람 30점, 그 뒤로 1점씩 감소(최소 1점). 팀전에서는 팀에서 가장 빨리 맞힌 사람 기준으로 팀 순위를 매겨 30·29·28·27점. [되돌리기] 한 번으로 전체 취소.
- MC 폰이 연결되면 전광판의 MC QR 은 자동으로 숨겨집니다 ([MC QR 다시 보기]로 다시 표시).
- **재입장:** 같은 폰·같은 브라우저로 다시 들어오면 자동으로 이어집니다. 다른 브라우저(예: 카카오톡 QR 스캐너 → 기본 카메라)나 저장소가 지워진 폰이라도 **전과 같은 닉네임**으로 입장하면 기존 참가자의 점수·팀을 이어받아요. 단, 그 닉네임의 기존 기기가 지금 사용 중이면 동명이인으로 보고 새 참가자로 등록합니다.
- 음악: 유튜브 공식 영상을 가려 둔 채 하이라이트 구간만 1초/3초/5초 재생, 정답 공개 시 영상 표시. **노래가 끝나야 버저가 열리고**, 다시 들려줄 때는 재생 동안 버저가 잠시 닫혀요(누른 순서는 유지).
- 전광판 패널의 비밀 정답지는 빔프로젝터에 노출되지 않도록 기본으로 가려져 있고, 누르고 있는 동안만 보입니다.

## 내장 콘텐츠

| 퀴즈 | 입력 | 카테고리 (각 20문제) |
|---|---|---|
| 🔤 초성 | 버저 | 음식 / 영화·드라마 / 동물·식물 / 사자성어·속담 |
| ⭕ OX | O·X | 과학 상식 / 한국사 / 생활·건강 / 세계 문화 |
| 🔢 4지선다 | 1~4번 | 세계 지리 / 스포츠 / 인물 / 맞춤법·우리말 |
| 😎 이모지 | 버저 | 영화 / 속담 / 나라·장소 / 직업·물건 |
| ⚡ 스피드 | 버저 | 넌센스 / 아재개그 / 신조어·줄임말 / 숫자 상식 |
| 🎵 1초 음악 | 버저 | 최신 K-POP 50곡 / 인기 K-POP 50곡 |

- 문제는 `src/data/quizzes/*.ts` 에 있어요. 초성 퀴즈는 정답만 적으면 초성이 자동으로 만들어집니다.
- 음악은 유튜브 공식 영상(임베드 허용 확인)의 "가장 많이 다시 본 구간"부터 재생해요. 어색한 곡은 전광판 패널 [🛠 도구 → 곡 구간 조정]에서 시작 위치·영상을 바꿀 수 있고, 노트북에 저장됩니다.
- 효과음(버저·정답·오답·시작·째깍·시간 종료·점수·입장·팡파르)은 Web Audio 로 실시간 합성. 전광판 상단에서 끌 수 있어요.
- [🏆 순위 발표] 버튼으로 현재 모드(개인/팀) 시상대 화면을 띄웁니다.

## 배포

`npm run build` → `dist/` 폴더를 그대로 GitHub Pages 또는 Vercel 에 올리면 됩니다 (`base: './'` 로 하위 경로에서도 동작).

## 구조

```
src/
  types.ts              도메인 타입 (Player.personalScore / Team.teamScore 독립)
  game/reducer.ts       모든 게임 로직 — 개인전 점수와 팀전 점수를 섞는 경로 없음
  game/selectors.ts     순위·공개/MC 스냅샷 분리
  game/bots.ts          시연용 봇 (실제 참가자와 같은 액션 사용)
  net/protocol.ts       PeerJS 메시지 정의
  net/hostPeer.ts       전광판(호스트) 네트워크
  net/clientPeer.ts     폰 네트워크 (자동 재접속, 하트비트)
  components/           ControlPanel(전광판·MC 공용), Leaderboard, QRCard …
  screens/              board / mc / player
```

> 통신: PeerJS 공개 시그널링 서버는 연결을 맺을 때만 사용되며, 게임 데이터는 브라우저끼리 직접(P2P) 주고받습니다.
